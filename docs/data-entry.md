# 여행 데이터 추가 준비

현재 저장소에는 실제 MySQL 여행 데이터가 포함되지 않습니다. 기존 PC에서 DBeaver로 `scripts/review_travel_data.sql`의 SELECT 문들을 실행한 후, 각 결과를 헤더가 포함된 CSV로 내보내 주세요.

여행, 방문 국가, 방문 도시 및 기존 국가/도시 ID를 대조하여 누락된 기록만 추가합니다. 여행명과 실제 날짜를 확인한 다음 기존 ID를 사용하는 INSERT를 작성합니다. 정확한 방문일이 없는 기록은 임의로 날짜를 넣지 않습니다.

웹 입력 순서: `/trips`에서 여행 추가 → 여행 상세에서 방문 국가 추가 → 국가명을 눌러 방문 도시 추가. 국가·도시가 선택 목록에 없다면 해당 관리 화면에서 먼저 등록합니다.

달력은 실제 여행 기간의 양끝 날짜를 모두 표시합니다. 기존 `stayed_day` 계산(종료일−시작일)은 변경하지 않습니다. 같은 날짜에 이동한 두 나라가 함께 나오는 것은 정상입니다. 국가·도시의 기간이 비어 있으면 해당 날짜의 위치를 추정하지 않습니다.
