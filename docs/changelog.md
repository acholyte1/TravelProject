## 2026-10-06 — 여행 만년달력과 관리 화면 테마

- `/calendar`: 월·일 기준으로 여러 해의 여행을 조회. 요일 없음, 윤년 2월 29일 지원.
- 여행 시작일/종료일 모두 표시하며, 연도별 실제 날짜는 유지.
- 국가·도시는 각 방문 기간이 해당 날짜를 포함할 때만 표시. 누락된 날짜는 추정하지 않음.
- 날짜 누락/역전 여행은 제외 개수를 안내. DB 장애는 빈 기록과 구분해 503 안내.
- 국가·도시·여행 관리 및 상세 화면에 `/travel` 색상과 공통 내비게이션 적용.
- 기존 폼 action, 필드명, 검색/정렬/수정 동작 유지.
- `scripts/review_travel_data.sql`: 데이터 추가 전 현황 확인용 읽기 전용 조회. 실제 데이터 삽입은 미실행.
- 스키마 변경 없음. Flask 재시작 후 `/calendar`에서 확인.
